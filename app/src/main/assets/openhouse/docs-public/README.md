# OpenHouseAI 文档

本目录保留三类说明：

1. 运行环境说明：见 `ENVIRONMENT.md`。
2. Codex、Claude Code 和 CloudCLI 的登录/API 配置：见 `MODEL_API_SETUP.md`。
3. 退役外部工具的可选外部安装参考：见 `OPTIONAL_EXTERNAL_TOOLS.md`。

如果 Agent 需要先了解当前手机环境，应先读 `ENVIRONMENT.md`。如果用户要配置默认核心 AI 能力，应读 `MODEL_API_SETUP.md`。只有在用户明确要求退役外部工具时，才读 `OPTIONAL_EXTERNAL_TOOLS.md`。
