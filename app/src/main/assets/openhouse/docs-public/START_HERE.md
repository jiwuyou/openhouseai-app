# 从这里开始

OpenHouseAI 文档分为三部分：

1. `ENVIRONMENT.md`：说明当前 Android、Termux、Ubuntu、路径和安装范围。
2. `MODEL_API_SETUP.md`：说明 Codex、Claude Code 和 CloudCLI 如何登录，或如何配置大模型 API。
3. `OPTIONAL_EXTERNAL_TOOLS.md`：说明退役外部工具的可选外部安装方式。

建议顺序：
- 先读 `ENVIRONMENT.md`，确认当前运行在哪里。
- 如果要使用 Codex、Claude Code 或 CloudCLI，再读 `MODEL_API_SETUP.md`。
- 只有用户明确要求退役外部工具时，才读 `OPTIONAL_EXTERNAL_TOOLS.md`。这些工具不是 APK 默认内置能力。
